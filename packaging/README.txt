PromptDock
好用的提示词，随叫随到。

这是 Windows 10/11 x64 的本地提示词工具，不需要安装 Python 或 .NET。

开始使用
1. 将整个 ZIP 解压到有写入权限的独立文件夹，双击 PromptDock.exe。
2. 在需要输入文字的窗口中点击输入框，按 Ctrl+Alt+P。
3. 按分类查找或输入关键词搜索，选择提示词，按 Enter 插入正文。

按需修改粘贴的正文，填入自己的问题或上传文件，最后由您自己发送。
PromptDock 只粘贴正文，不自动发送。

自己新建
从托盘菜单打开“管理提示词”→“新建”，填写名称和正文，保存即可。
不需要编辑 JSON；分类和标签可选。

软件更新
从托盘、浮窗“⋯”或管理窗口打开“检查软件更新”。当前本地准备版本
尚未配置官方更新仓库，会显示“更新源尚未启用”。正式启用后，后台仅
检查版本；只有点击“更新并重启”才会下载，先处理未保存编辑并备份数据。
可以在软件更新窗口关闭自动检查。内置提示词更新另走管理窗口的预览确认。

备份与退出
个人数据位于 %LOCALAPPDATA%\PromptDock\library.json。
可通过管理窗口“导出 JSON”备份；或退出程序后复制数据目录。
软件更新前自动备份到同目录 backups\pre-update-*\library.json。
恢复时先退出程序，保存当前库副本，再恢复与程序版本兼容的备份。
右键系统托盘图标→“退出”，即可完整退出。

卸载
先退出 PromptDock，再运行同目录 Uninstall.exe。确认后仅删除随包程序
及说明文件，个人库、设置、备份和不属于发布包的文件保留。
本程序是解压即用版，不写入系统安装记录，不需要管理员权限。
