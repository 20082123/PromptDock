PromptDock
Windows 10/11 x64 提示词工具

使用
1. 解压 ZIP，双击 PromptDock.exe。
2. 点击目标输入框，按 Ctrl+Alt+P。
3. 按分类查找或搜索，选中提示词，按 Enter 或点击“插入”。

只粘贴正文，不自动发送。粘贴失败时可手动按 Ctrl+V。
右键可查看全文、复制、收藏或编辑。

新建提示词
托盘菜单→“管理提示词”→“新建”，填写名称和正文后保存。
分类和标签可选，也可导入或导出 JSON。

更新与备份
在托盘、浮窗“⋯”或管理窗口点击“检查软件更新”。
官方版从 GitHub 获取新版；点击“更新并重启”后安装，安装前自动备份个人库。
内置提示词更新在管理窗口预览确认，保留个人修改和使用记录。

数据位置：%LOCALAPPDATA%\PromptDock\library.json
自动备份：同一数据目录下 backups\pre-update-*\library.json
手动备份：管理窗口→“导出 JSON”。

退出与卸载
右键托盘图标→“退出”。卸载时运行同目录 Uninstall.exe，个人库和备份会保留。
